# 第三轮：估计定位与地面接触建模

2026-09-27。目标继续进行；本轮没有实体机器狗连接或运动。

## 从回放到在线估计

增加隔离的激光里程计进程、固定依赖环境、输入契约和失效锁存。估计器只读取机体点云和扫描时间，导航使用估计位姿配准点云、投影候选和解释 RGB-D；真值轨迹仅供外部评测。相机、雷达现在可选择随机身旋转的刚性安装模式。默认理想定位基线保留。

三段旧记录的 GICP 回放位置最大误差均小于 0.1 m；KISS 对照在开发段末端漂移 3.29 m。数值正常不能证明可靠定位，所有估计结果仍标注 `control_ready: false`。51 项软件测试通过，包含新增加的真值字段拒绝、退化点云拒绝、时间异常与失效锁存；这些不替代真实定位验证。

首次刚性安装的在线闭环 `office-lounge-008-gicp-v4` 在约 11.4 s 失效，最大位置误差 0.703 m。稀疏 11 线扫描在机体转动后不再复现旧的世界稳定扫描效果。单独改变运动预测或下采样分辨率未解决。下一项 `office-lounge-009-gicp-dense` 将竖直采样改为 64 线；任务仍使用在线估计，不向策略开放真值。详细回放表、命令和传感器假设见 [定位接入记录](localization.md)。

009 已完成：119.915 s、30.936 m，600 帧定位有效；无噪声虚拟扫描的位置最大误差 1.013 mm，处理 p95 72.2 ms。完整仿真耗时 608.1 s。29 次 VLM 调用后仍未完成两位置确认，因此任务计为超时失败；没有非脚部物理接触，不能据此声称 G3 或 G4 通过。

目前视觉验证的主要失败表现为：VLM 识别出家具组，但所报桌面像素位于椅面、桌沿或腿部，几何检查拒绝到达。继续保留这些拒绝。下一轮准备从 RGB-D 提取水平表面候选，让 VLM 选择候选并判断物体归属，仍由两位置证据确认停止。

## 训练与接触差异

v4 从 v3 继续训练 1000 次更新，2048 个并行环境，使用三角网格平地及 0–2 cm 低矮障碍；完成权重为 `model_2796.pt`，SHA-256 `23c5abb0b5a9e29080752fa085e5b84f310685b23943f8b2ada017e49e9ea931`。训练运行耗时约 23.6 分钟，未替换默认权重。

`control-v4-box-yaw0`：前进 RMS 0.0223 m/s，但正反转向 RMS 0.409/0.393 rad/s，仍失败。四只脚均有受力，但接触审计检出 1 次左后小腿异常接触记录，接触门槛也未通过。继续增加训练量没有依据，需先解释物理差异。

审查 Isaac Sim 5.1 的实际安装源码发现两点：

1. `GroundPlane` 包装器额外给可视 `/geom` 开启碰撞，原先的平面对照实际有两个碰撞面。新增 `plane_clean` 关闭可视面碰撞，只保留明确绑定材料的解析平面；v3 仍能正确双向转向，说明重叠碰撞不是该现象的充分解释。
2. `FixedCuboid` 创建新物体时写入 `contactOffset=0.1`、`torsionalPatchRadius=1.0`、`minTorsionalPatchRadius=0.8`。因此“只替换几何”的旧描述不充分：高层包装器同时改变了接触参数。新增独立参数对照，只改变地面/门槛的扭转半径，保持同一 v3 权重、实体楼板、摩擦系数、求解器及动作序列。测试半径 0、0.01、0.02 m；不能把其中任何一项直接称作经过实机标定的脚掌模型。

参数对照结果（同一 v3、同一实体楼板）：

| 半径设置 | 正/反转向 RMS，rad/s | 单朝向动作/接触检查 |
|---|---|---|
| 包装器默认 1.0 / 0.8 m | 约 0.422 / 0.427 | 失败 |
| 0 / 0 m | 0.0197 / 0.0178 | 通过 |
| 0.01 / 0.01 m | 0.1167 / 0.1164 | 通过 |
| 0.02 / 0.02 m | 0.2334 / 0.2492 | 转向失败；接触通过 |

名义六项套件明确使用 PhysX 默认的刚性点接触（地面扭转半径 0），对应 Office 网格地面和训练的接触假设；普通摩擦、实体楼板、门槛及验收误差阈值均保留。1 cm/2 cm 对照说明仿真关节控制器仍对软脚接触假设敏感，不能把通过名义模型写成真实脚掌适配。实机继续使用厂商高层运动接口。

v4 的单次异常小腿接触记录位于离地约 0.596 m、报告穿透约 1.124 m，与地面几何明显不一致；它仍使该次接触门槛失败。新增事件类型和数据偏移日志供后续核查，不把该异常直接解释成真实腿部碰撞，也不删除记录来判定通过。

这些参数控制接触产生的扭转阻力，PhysX 标准默认半径为 0；[官方碰撞参数说明](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.2/dev_guide/schemas/physxschema.html) 和 [扭转摩擦说明](https://nvidia-omniverse.github.io/PhysX/physx/5.5.0/_api_build/classPxShape.html)。实际安装文件已保存在本机 `data/readiness/physics-sources/`，每次诊断另存接触参数和控制源码。
