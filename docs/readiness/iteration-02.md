## 已完成的证据

### 休息区闭环

`data/sim/office/runs/office-lounge-006-surface` 使用多尺度法向检查和原始 Go2 权重，71.215 秒仿真时间、168.474 秒墙钟时间、11.840 米轨迹、18 次 VLM 调用后，在固定评测区内停稳。3 个接受锚点的高度约 0.452 米，均位于同一张桌面。原始接触点日志未检出非脚部物理接触；保留所有零冲量近邻事件。

该运行先于本轮的表面身份验证模块，不能用它宣称最新模块已完成在线闭环。它也不是冻结多起点评测。

### RGB-D 表面身份与关联

几何模块产生锚点所在的连通水平表面及 10 厘米 XY 格子集合；独立的 VLM 查询判断标记点属于桌面、椅子或其他表面。两次确认必须有足够的已观测表面重叠和一致高度，且相机实际移动 0.6–4 米，时间间隔不超过 60 秒。策略只处理 RGB-D；不读取 USD 物体标签。

`data/readiness/surface-hard-negative-v1`：固定 7 个回放样本全部符合开发复核，接受 3 个桌面，拒绝 2 个椅子表面、1 个墙面和 1 个地面。椅面在几何上能通过，但被身份查询拒绝。重复站位的两帧不完成，移动后的同桌第二视角完成关联。

这些像素由助手根据真实记录图像复核，既不是独立人工标注集，也不能据此声称对所有椅子、柜顶或陌生环境有效。所用配置：`config/readiness/surface-review.json`。所有模型请求、图片与回复保留。

### 步态独立检查

| 固定动作 RMS | 原始策略 | v1 改进策略 | v2 转向强化策略 |
|---|---:|---:|---:|
| 前进，m/s | 0.231 | 0.028 | 0.239 |
| 后退，m/s | 0.178 | 0.038 | 0.201 |
| 左侧移，m/s | 0.197 | 0.033 | 0.098 |
| 右侧移，m/s | 0.047 | 0.016 | 0.064 |
| 原地转向，rad/s | 0.462 | 0.468 | 0.386 |

v1、v2 都没有实际非脚部接触，但都未通过 G1。v2 的前进退步在官方 Isaac Lab 环境也能复现；其关节目标偏移极大，部分动作为 -16，不能据训练奖励判断通过。未替换默认权重。

v3 增加关节目标幅值惩罚，缩小低速误差奖励带宽并降低探索熵。在项目控制器里平移恢复（前进 0.026、后退 0.029、左侧移 0.025、右侧移 0.010 m/s），正向转动误差仍为 0.422 rad/s，未通过 G1。**同一 v3 权重在官方 Isaac Lab CUDA 环境中，四个平移误差为 0.022、0.015、0.018、0.011 m/s，转动误差为 0.018 rad/s。** 因而后续优先诊断运行时差异。仅对齐刚体/求解器参数或实例化形状摩擦材料还未消除差异；原始记录保存在 `control-v3-*` 目录。

进一步对照：官方环境 CPU 转动误差 0.014 rad/s；替换成官方 Isaac Lab 执行器但保留实体楼板，仍未通过；禁用关节系统休眠也未改善。**只把诊断中的实体楼板换成无限平面，保持原控制器与 v3 权重，双向转动 RMS 均约 0.023 rad/s，完整单朝向动作检查通过。** 这将问题缩小到地面碰撞几何带来的接触差异；并未证明具体的接触求解机理。

无限平面通过不替代实体楼板验收。v4 保持 v3 奖励，改用三角网格平地和 0–2 cm 低矮网格障碍训练，以减少对理想平面接触的依赖。独立门槛、三朝向和 Office 任务结果仍待完成。

所有低层权重只用于仿真，不是实机部署控制器。原始权重保持不变。

### ROS 2 无运动门控

`data/readiness/ros-guard-bench-v2` 在本机环回 DDS domain 94 注入合成消息，不包含机器人传输：

| 注入故障 | 接收停车状态延迟 |
|---|---:|
| 指令超时 | 245 ms |
| 机器人连接心跳消失 | 235 ms |
| 无效定位 | 20 ms |
| 非有限速度 | 4 ms |
| 空点云 | 10 ms |
| 缺少点云坐标字段 | 9 ms |
| 非有限点云 | 15 ms |
| 松开使能 | 20 ms |
| 急停 | 4 ms |

九项均停车，恢复健康输入后均不会自行重新使能。这里的“停车”指门控输出归零，**不是实体制动延迟**。急停锁存，需明确处理后重新使能；尚无实机 SDK 连接、设备侧看门狗验证或实体制动距离数据。
