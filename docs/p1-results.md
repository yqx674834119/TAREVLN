## 发现的问题和验收边界

1. **Go2 步态仍不合格。** 接触回调记录 `FR_thigh` 与 EA 轿厢、EB 轿厢、A5 楼板、B1 楼板接触。不能删除这些记录，也不能用目标成功掩盖它们。下一步应对齐完整 IsaacLab 物理/材料/执行器配置，记录接触时刻、冲量、支撑裕量，并验证正常转向、门槛和轿厢进入；必要时替换或重新训练运动策略。本轮不宣称无碰撞通过。
2. **原地转向会停滞。** 发布策略在本配置的纯角速度命令下进入静止状态；基线使用 LiDAR 净空检查后的小弧线转向。它仍不能代表真实 Go2 控制器的狭窄空间能力。
3. **报告写入曾失败。** baseline-v5 已到目标，但 NumPy 布尔值使报告序列化失败，随后退出异常。保留原文件，用独立审计标为“轨迹条件满足、运行报告未完成”。修复类型转换和报告优先落盘后，baseline-v6 正常完成。新增 NumPy 回归测试。
4. **相机时间标签曾落后 0.1 s。** baseline-v6 图像读取直接来自当前 annotator，而相机内部 10 Hz 定时器偶尔漏更新 metadata。最终代码改为每次显式渲染都更新，并在控制开始后检查时间差不超过 0.01 s。不能把旧日志标成已经同步的 ROS 数据。
5. **第二张 GPU 的并行启动没有相机输出。** bridge-v1 因时间戳为 0 被检查主动拒绝；报告为 error。尚未定位 GPU 选择/多实例渲染的完整原因，默认验收使用 GPU 0。没有重启或修改系统驱动来绕过问题。
6. **标牌后背和遮挡影响识别。** 已为牌子增加不透光背板、调整相对位置，改用 ZXing。当前大尺寸二维码仍是联调工具，不能当成自然语言感知能力。
7. **GPU 动态库和 Isaac 生命周期问题已修复。** 补齐项目局部无版本动态库链接；禁用加载 USD 后自动新建空 stage；控制与渲染分离；接触 API 在 reset 前设置。这些均在实际仿真中验证。

进一步修正了“从其他楼层呼叫已关闭电梯时，原层门先短暂重开”的状态插值错误，纯测试验证原层门保持关闭。接触报告也从 actor 汇总改为 collider 级分类，仅允许足端与支撑面接触，避免把轿厢墙面或小腿接触统统当成正常支撑。旧路线报告保留原统计口径，不能与新口径直接合并。

正式研究系统还缺：TARE 的任务相关候选视点接口、冻结 VLM/OCR、3D 连接候选及跨视角关联、通用层级图重规划、关闭/错误/单向连接恢复、带噪定位与分层地图、ROS 2 bridge/TF/时间同步，以及跨场景强基线/消融。当前只把上述接口闭环用一个诊断策略串起来。

定位和载具假设也必须披露：使用理想仿真里程计；低层使用轿厢竖直速度作平台补偿；摄像头/LiDAR 配置不是实测 Go2 标定；电梯 API 负责呼叫和选层；没有爬楼或自主按键验收。**本轮没有真实机器狗或真实 MID360 闭环。**

## 测试分层

- 5090 Python 纯测试：13 项通过，包含电梯联锁、几何/先验隔离、错误停止拒绝和报告序列化。
- 本地纯测试：12 项通过，NumPy 运行时回归因本地未装 NumPy 跳过；5090 已补验该项。
- 离线策略回放：baseline-v5 的 2378 个策略输入帧，新增观察点回退前后状态、命令、请求、身份与已验证边数量全部一致。这是回放证据。
- Isaac 实际物理闭环：baseline-v6 基础路线、bridge-v2 连廊路线任务通过；接触质量未通过。
- 最终传感器短测：3.015 仿真秒、IMU 和隔离通过，collider 级接触记录正常落盘；检测到小腿碰撞体与楼板接触，严格足端支撑条件为 false。
- 独立直线关节控制检查：前进 3.074 m，本体碰撞盒最小净空 0.116 m，保持直立；这只验证基本运动，不覆盖全身接触质量。
- ROS 2/TARE/VLM 集成、真实设备回放、实体闭环：未完成。

## 如何迁移与需要准备的材料

先采用官方 Office 或 Hospital 的一块室内区域替换 P1 单层几何，检查碰撞、门净宽、标牌可读性和传感器噪声；再构造不同楼层与可执行电梯，最后接入室外粗地图。不要把单层场景简单复制并投影成一张二维占据图。

Office、Hospital、Simple Room 的入口 USD 已下载并记录 SHA-256；直接外部引用分别为 539、216、55。它们还不是完整离线资产包，Office 的电梯门动画也不是已验证的跨层载客技能。[官方环境资产](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/assets/usd_assets_environments.html) 和 [SceneBlox](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/replicator_tutorials/tutorial_replicator_sceneblox.html) 可提供室内素材和布局变化；跨楼宇任务、连接真值和交互仍需本项目补充。

迁移到香港科技大学（广州）和海港城，需要用户准备：可合法使用的楼层/建筑模型或采集条件、楼宇/楼层命名与入口/电梯/连廊真值、Go2 型号及传感器内外参/已验证能力。地图方面还需要高德 Web 服务 Key、OSM/高德与场景的坐标配准及可通行性核验。目前 P1 使用合成粗地图；已有真实 OSM 快照尚未与场景对齐，高德无密钥路径只能返回结构化缺钥状态。
