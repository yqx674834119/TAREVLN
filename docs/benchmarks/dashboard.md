# 仿真可视化前端

地址：`http://127.0.0.1:8878/`。HTTP 服务在 5090，仅监听其 loopback；Mac 通过 SSH 转发同一端口。已在 Codex 浏览器打开。

## 使用

1. 左侧选 **Isaac 机器狗** 或 **MP3D 基准**，再选任务。任务指令会在中间显示。
2. 机器狗模式可选 30／60／120／300 秒仿真预算。点击“开始仿真”；初始化、模型请求与仿真会耗费实际时间。
3. 机器狗模式提供第三视角和前视 RGB；MP3D 模式显示 Habitat RGB，不把它画成机器狗。
4. “跟随最新”显示最新观测；时间轴、播放和倍速用于历史回放。Isaac 图像每约 2 秒仿真时间采样，属于观测帧流，不是高帧率视频或交互式自由相机。
5. 右侧按当前帧时间显示视觉证据、候选选择、简短决策理由、模型自报置信度。内容来自实际输出日志，不提供隐藏推理。轨迹来自仿真运行记录。
6. “停止本次”只允许停止本控制台启动的当前任务；历史运行、其他任务与实体机器狗不受控制。

当前包含 2 个 Isaac 语义任务和首个 MP3D 场景的 102 条 R2R-CE 指令。一次仅允许一个控制台仿真运行。历史运行来自不同代码配置，旧报告的 success 字段不表示当前完整系统已通过验收。

## 运行配置

Isaac 使用现有 Go2 v5 rails checkpoint、GICP、uniform64 虚拟 LiDAR、TARE、SAM2 和 metric-plane 视觉接地模块。继承现有动态链接 GPU 兼容脚本，不修改实体机器人参数或生产 TARE_WheelTECH。

Habitat 使用本轮的单前视 VLM adapter，0.25m 前进／15°转向，上限 500 原子动作及 130 次模型请求。它没有 Go2 物理或 TARE。本界面的交互测试结果不合并进已固定的 10 条 pilot 统计。

模型凭据只由后台 worker 从 `~/VLN/secrets/` 读取，前端不接受或返回 API Key。浏览器端仅收到白名单化的决策字段与 JPG/PNG；API 的媒体路径不能越过对应运行目录。服务检查 Host、同源 Origin 与自定义请求头；目前用于 SSH loopback，不是公网多人服务。

## 启动与恢复

5090：

```bash
cd ~/VLN/cross-building-floor-nav
nohup ../envs/bench-fetch/bin/python scripts/dashboard/server.py \
  > ../logs/dashboard-server.log 2>&1 < /dev/null &
```

已有服务运行时不要重复启动。服务器 PID 记录在 `~/VLN/logs/dashboard-server.pid`；重启控制台之前先停止它持有的任务并确认进程退出，避免失去任务归属状态。

Mac 转发：

```bash
ssh -N -L 127.0.0.1:8878:127.0.0.1:8878 5090
```

本次已建立后台转发；再次转发前检查端口是否已占用。前端资源位于 `frontend/`，后台是 `scripts/dashboard/server.py`，无需 Node 构建和外部 CDN。

模型请求沿用现有项目私有 CONNECT 中继 `127.0.0.1:18119`，只转发 DeepSeek TLS。中继不在线时 API 请求会失败并保留记录；不要通过修改系统 VPN/DNS 规避。后台下载独立于本前端，即使关闭浏览器仍继续。
